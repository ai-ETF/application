# AI-ETF 设计系统 (Design System)

本文档定义了 AI-ETF 应用的视觉设计规范，采用统一的暖色调体系，确保产品界面的一致性和可维护性。

---

## 色彩体系 (Color System)

### 背景色

| 名称 | 色值 | 用途 |
|------|------|------|
| 页面背景色 (Background) | `#F9F6F0` | 暖米色调，页面整体背景 |
| 内容容器色 (Surface/Card) | `#FFFFFF` | 卡片、容器背景 |

### 品牌色 - 温暖琥珀系

| 名称 | 色值 | 用途 |
|------|------|------|
| 主品牌色 (Primary) | `#B45309` | 琥珀棕，用于主按钮、激活状态、用户对话框 |
| 悬浮交互色 (Primary Hover) | `#92400E` | 深琥珀，主按钮悬浮状态 |
| 浅品牌色 (Primary Light) | `#FBBF24` | 浅琥珀，辅助装饰、高亮、AI头像渐变 |
| 品牌背景色 (Primary Background) | `#FEF3C7` | 浅琥珀背景，高亮区域背景 |

### 文本色 - 暖调深色

| 名称 | 色值 | 用途 |
|------|------|------|
| 主文本色 (Text Primary) | `#2D1E16` | 深棕色，标题与正文 |
| 次文本色 (Text Secondary) | `#78716C` | 暖灰色 (Stone 500)，辅助说明、时间戳 |
| 辅助文本色 (Text Tertiary) | `#A8A29E` | 浅暖灰 (Stone 400)，禁用状态、提示 |

### 边框色 - 暖调边框

| 名称 | 色值 | 用途 |
|------|------|------|
| 边框/分割线 (Border) | `#E0D8CE` | 暖调浅棕，分割线、边框 |
| 浅边框 (Border Light) | `#F5F0EB` | 更浅的暖边框，微妙分隔 |

### 语义色 - 符合中国市场惯例

| 名称 | 色值 | 用途 |
|------|------|------|
| 上涨色 (Up/Success) | `#DC2626` | 红色 (Red 600)，表示上涨、成功状态 |
| 上涨背景色 (Up Background) | `#FEF2F2` | 浅红色背景，上涨数据标签 |
| 下跌色 (Down/Danger) | `#16A34A` | 绿色 (Green 600)，表示下跌、风险状态 |
| 下跌背景色 (Down Background) | `#F0FDF4` | 浅绿色背景，下跌数据标签 |
| 警告色 (Warning) | `#D97706` | 深琥珀 (Amber 600)，警告提示信息 |
| 警告背景色 (Warning Background) | `#FFFBEB` | 浅琥珀背景，警告提示 |

> **涨跌色说明：** 中国/港台/日本市场惯例为"红涨绿跌"，与欧美市场相反。本设计符合目标用户认知习惯。

## 字体体系 (Typography System)

### 字体家族

| 类型 | 字体 | 用途 |
|------|------|------|
| 主字体 (Sans-serif) | `Inter, -apple-system, sans-serif` | 正文、标题、按钮等 |
| 数据字体 (Monospace) | `JetBrains Mono, Roboto Mono` | 金额、股票代码等数据展示 |

### 字号规范 (Font Sizes)

| 级别 | 大小 | 用途 |
|------|------|------|
| 2xl | **32px** | 大标题、总资产 |
| xl | **24px** | 一级标题、模块标题 |
| lg | **20px** | 二级标题、卡片标题 |
| base | **16px** | 正文、AI对话 |
| sm | **14px** | 辅助说明、输入框提示 |
| xs | **12px** | 标签、微型文本 |

### 字重规范 (Font Weights)

| 字重 | 数值 | 用途 |
|------|------|------|
| Regular | 400 | 基础正文、对话气泡 |
| Medium | 500 | 按钮、次级标题、表头 |
| SemiBold | 600 | 核心模块标题、关键财务数据 |

## 间距体系 (Spacing System)

基于 **8px 栅格** 的间距规范：

| 间距值 | 用途 |
|--------|------|
| 2px | 微调间距，如图标与文字 |
| 4px | 组件内部极小间距，如数据标签内部 |
| 8px | 关联元素间距，如列表项之间 |
| 16px | 基础内边距 (Padding)、段落间距 |
| 24px | 独立模块内边距、卡片间距 |
| 32px | 页面区块间距 |
| 48px | 大型页面分栏间距 |

---

## 圆角规范 (Border Radius)

| 级别 | 数值 | 用途 |
|------|------|------|
| xs | 2px | 极小标签、复选框 (Checkbox) |
| sm | 6px | 基础按钮、输入框、下拉菜单项 |

## 阴影规范 (Shadow System)

基于暖调深棕色 `rgba(45, 30, 22, x)`，与暖色背景协调。

### 小阴影 (Shadow-SM)

用于悬浮按钮、下拉框：

```css
box-shadow: 0 1px 2px 0 rgba(45, 30, 22, 0.06);
```

### 中阴影 (Shadow-MD)

用于悬浮卡片、工具提示 (Tooltip)：

```css
box-shadow: 0 4px 6px -1px rgba(45, 30, 22, 0.10), 0 2px 4px -2px rgba(45, 30, 22, 0.05);
```

### 大阴影 (Shadow-LG)

用于全局弹窗、侧边抽屉 (Drawer)：

```css
box-shadow: 0 10px 15px -3px rgba(45, 30, 22, 0.10), 0 4px 6px -4px rgba(45, 30, 22, 0.05);
```

### 内阴影 (Shadow-Inner)

用于输入框内部、按下状态：

```css
box-shadow: inset 0 2px 4px 0 rgba(45, 30, 22, 0.05);
```

## 使用指南

### 颜色使用原则

1. **背景层次**：页面使用 `#F9F6F0`，卡片/容器使用 `#FFFFFF` 形成层次
2. **文本层级**：主文本用 `#2D1E16`，辅助文本用 `#78716C`
3. **交互反馈**：主按钮用 `#B45309`，悬浮时用 `#92400E`
4. **数据展示**：上涨用 `#DC2626` 红色，下跌用 `#16A34A` 绿色
5. **色温统一**：所有颜色均为暖色调，与米色背景协调

### 间距使用原则

1. 遵循 8px 栅格体系，避免随意间距
2. 相关元素使用较小间距 (4px-8px)
3. 独立模块使用较大间距 (16px-32px)

### 圆角使用原则

1. 小型元素使用小圆角 (2px-6px)
2. 卡片类使用中等圆角 (12px)
3. 头像、药丸按钮使用全圆角 (9999px)

## 配色调整说明

本设计系统经过以下优化：

| 问题 | 原配色 | 新配色 | 说明 |
|------|--------|--------|------|
| 暖底+冷色品牌色割裂 | `#2563EB` 冷蓝 | `#B45309` 琥珀棕 | 统一为暖色调 |
| 文本色偏冷 | `#0F172A` 冷黑 | `#2D1E16` 深棕 | 暖调深色 |
| 次文本色偏冷灰 | `#64748B` 冷灰 | `#78716C` 暖灰 | Stone 色系 |
| 边框色在米底上太淡 | `#E2E8F0` 冷灰 | `#E0D8CE` 暖棕 | 提高对比度 |
| 涨跌色与国内惯例相反 | 绿涨红跌 | 红涨绿跌 | 符合中国市场 |
| 警告色与米底对比不足 | `#F59E0B` | `#D97706` | 加深提高对比度 |
