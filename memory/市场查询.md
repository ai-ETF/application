# AI-ETF 后端 API 测试命令清单

> 后端地址：`http://47.113.220.182:8000`
> 测试时间：2026-07-24
> 认证方式：所有受保护接口需要在 Header 中携带 `Authorization: Bearer <token>`

**前置步骤**：所有受保护接口（market、watchlist、secure-chat）需要先登录获取 JWT token：

```bash
# 登录获取 token（替换为实际邮箱密码）
TOKEN=$(curl -s -X POST "http://47.113.220.182:8000/api/secure-chat/login" \
  -H "Content-Type: application/json" \
  -d '{"email": "your@email.com", "password": "your-password"}' | python3 -c "import sys,json; print(json.load(sys.stdin)['access_token'])")
echo "TOKEN=$TOKEN"
```

后续命令中 `$TOKEN` 代表这个变量。

curl -s $API/api/market/money-flow/512890 -H "Authorization: Bearer $TOKEN" | python3 -m json.tool 2>/dev/null | head -15

echo -e "\n=== 8. 分类 ==="
curl -s $API/api/market/categories -H "Authorization: Bearer $TOKEN" | python3 -m json.tool 2>/dev/null | head -15

## 附录：Token 获取与常见问题

### 获取 token 并设为环境变量

```bash
# 替换为真实邮箱密码
TOKEN=$(curl -s -X POST "http://47.113.220.182:8000/api/secure-chat/login" \
  -H "Content-Type: application/json" \
  -d '{"email": "test@example.com", "password": "your-password"}' \
  | python3 -c "import sys,json; print(json.load(sys.stdin)['access_token'])")
echo "TOKEN=$TOKEN"
export TOKEN
```

### 验证 token 是否生效

```bash
# 有 token 应返回行情数据
curl -s "http://47.113.220.182:8000/api/market/spot/512890" \
  -H "Authorization: Bearer $TOKEN" | head -5

# 无 token 应返回 401
curl -s "http://47.113.220.182:8000/api/market/spot/512890"
# 预期输出: {"detail":"认证格式错误，应为 Bearer <token>"}
```
