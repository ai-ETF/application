# 登录功能设计方案

**数据库文件**: `src/types/supabase.ts`
使用 Supabase 内置 `auth.users` 表，不允许修改数据库表。

## 数据流转

```
┌─────────────┐      ┌──────────────────┐      ┌─────────────┐
│ LoginForm   │ ───→ │ useSupabaseAuth  │ ───→ │ Supabase    │
│ (Vue组件)    │      │ (composable)     │      │ Auth API    │
└─────────────┘      └──────────────────┘      └─────────────┘
                            │
                            ↓
                     ┌──────────────┐  
                     │ authStore    │ 
                     │ (Pinia)      │      
                     └──────────────┘      
```

## 组件职责划分

### Vue 组件层 (LoginForm.vue)
- 只负责 UI 和表单收集
- 调用 composable 方法，不直接碰 Supabase
- 处理 loading 状态和错误展示

```ts
// LoginForm.vue
const { login, loading } = useSupabaseAuth()

const handleLogin = async () => {
  console.log('[LoginForm] 开始登录流程', { email: email.value })
  const { error } = await login(email.value, password.value)
  if (error) {
    console.error('[LoginForm] 登录失败:', error)
    errorMessage.value = error
  } else {
    console.log('[LoginForm] 登录成功，跳转首页')
    router.push('/chat')
  }
}
```

### Composable 层 (useSupabaseAuth.ts)
- 封装所有 Supabase 认证 API 调用
- 返回响应式状态和方法给组件使用
- 调用 Pinia store 同步状态

#### 核心代码示例

```ts
// useSupabaseAuth.ts
export const useSupabaseAuth = () => {
  const authStore = useAuthStore()
  const loading = ref(false)

  const login = async (email: string, password: string) => {
    console.log('[useSupabaseAuth] 调用 supabase.auth.signInWithPassword')
    loading.value = true
    const { data, error } = await supabase.auth.signInWithPassword({ email, password })

    if (error) {
      console.error('[useSupabaseAuth] Supabase 返回错误:', error.message)
    } else {
      console.log('[useSupabaseAuth] 登录成功，用户ID:', data.user?.id)
      authStore.setUserFromSupabase(data.user)
    }
    loading.value = false
    return { user: data?.user, error: error?.message }
  }

  return { login, loading, ... }
}
```

### Pinia Store 层 (auth.ts)
- 存储用户状态，提供 `isAuthenticated` 计算属性
- **持久化到 localStorage**，刷新页面不丢失登录态

```ts
// stores/auth.ts
export const useAuthStore = defineStore('auth', () => {
  const user = ref<User | null>(null)
  const isAuthenticated = computed(() => !!user.value)

  const setUserFromSupabase = (supabaseUser: SupabaseUser | null) => {
    console.log('[authStore] setUserFromSupabase 被调用', { userId: supabaseUser?.id })
    user.value = supabaseUser ? { id: supabaseUser.id, email: supabaseUser.email } : null
  }

  return { user, isAuthenticated, setUserFromSupabase }
}, {
  persist: { storage: localStorage }  // 关键：自动持久化
})
```

## 总结：谁调用谁

```
LoginForm.vue
    ↓ 调用
useSupabaseAuth().login()
    ↓ 调用
supabase.auth.signInWithPassword()
    ↓ 成功后调用
authStore.setUserFromSupabase()
    ↓ 自动持久化到
localStorage
```
